## 📌 Overview

AI Lead Generator is a smart lead generation and outreach platform designed to help businesses, freelancers, startups, and sales teams discover prospects, manage leads, and automate personalized email campaigns.

The platform combines AI-powered email generation, lead management, prospect tracking, and email automation into a single streamlined workflow.

---

## ✨ Features

### 🎯 Lead Management

* Add and organize prospects
* Store LinkedIn profiles and contact information
* Lead status tracking
* Search and filter leads

### 🤖 AI-Powered Email Generation

* Generate personalized cold emails
* Create follow-up sequences
* Improve response rates with AI-assisted content

### 📧 Email Automation

* SMTP integration
* Send emails directly from the platform
* Automated outreach workflow
* Email campaign management

### 📊 Dashboard & Analytics

* Lead overview dashboard
* Prospect tracking
* Campaign monitoring
* Database-backed storage

### 🔐 Authentication System

* Secure login system
* User account management
* Protected dashboard access

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/AnvithGangula/Lead-Generator-LinkedIn-and-Email-using-AI.git
```

### Navigate to Project

```bash
cd Lead-Generator-LinkedIn-and-Email-using-AI
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Environment

Windows

```bash
venv\Scripts\activate
```

Linux / Mac

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Application

```bash
streamlit run app.py
```
